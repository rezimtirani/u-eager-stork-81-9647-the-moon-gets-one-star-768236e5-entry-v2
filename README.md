A one-star review of the moon, written as a program: the moon works the
night shift, steals all its light from the sun, and still gets the
poems, while the reviewer does overtime and nobody writes them a
sonnet. `main.py` writes the single review line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.

This is the corrected edition of the entry: the first version's line was
129 characters, over the sealed gate of 120 characters in the kit's
RULES.txt, so it would have scored Valid=0. This line is 114
characters — inside the gate.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
